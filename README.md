# Лаборатори №6 — Category-Partition ба PICT

**Оюутан:** Оюунсүрэн Мөнхзолбоо  
**Оюутны код:** 210910878

## A. Category-Partition — Банкны шилжүүлэг

**Тестлэх тодорхойлолт:** `POST /transfer` — `{ "from": ID, "to": ID, "amount": NUM, "currency": CODE }`. Энэ лабораторид API код ажиллуулахгүй; оролтын ангилал, хязгаарлалт, хүлээгдэх үр дүнг тодорхойлно.

### A1. Сонголт ба төлөөлөх утгууд

Туршилтын орчин: `A001` — идэвхтэй, царцаагдаагүй, MNT данс; үлдэгдэл 1,000,000 MNT, өдрийн ашиглах боломжтой лимит 500,000 MNT. `A002` — өөр хүний идэвхтэй MNT данс. `A003` — царцаагдсан данс. `A004` — идэвхтэй USD данс. `X999` — байхгүй данс. Хөрвүүлэлтийн жишээнд **зөвхөн тестийн өгөгдөл болгон** `1 USD = 3,500 MNT` гэж үзэв; бодит банкны ханш гэж ойлгохгүй.

| Категори | Сонголт | Төлөөлөх утга / тайлбар | Тэмдэглэгээ |
|---|---|---|---|
| From | Valid | `A001`, хүчинтэй, царцаагдаагүй | Энгийн |
| From | Frozen | `A003`, царцаагдсан | `[ERROR]` |
| From | Missing | `X999`, данс байхгүй | `[ERROR]` |
| To | Valid | `A002`, илгээгчээс өөр хүчинтэй данс | Энгийн |
| To | Missing | `X999`, хүлээн авагч байхгүй | `[ERROR]` |
| To | SameAsFrom | `A001` (`from=A001` үед) | `[ERROR] [IF From=Valid]` |
| Amount | Zero | `0` | `[ERROR]` |
| Amount | Negative | `-1` | `[ERROR]` |
| Amount | Normal | `100,000 MNT` | Энгийн |
| Amount | OverBalance | `1,100,000 MNT` (үлдэгдэл 1,000,000) | `[ERROR] [IF From=Valid]` |
| Amount | OverLimit | `600,000 MNT` (үлдэгдэл хүрэлцээтэй, лимит 500,000) | `[ERROR] [IF From=Valid]` |
| Currency | Same | `MNT`, дансны валюттай ижил | Энгийн |
| Currency | Different | `USD`, илгээгчийн дансны валютаас өөр | `[IF From=Valid]` |

**Далд орчны нөхцөл:** Илгээгчийн үлдэгдэл, тухайн өдрийн өмнө хийсэн шилжүүлгүүдээс хамаарах үлдсэн лимит, дансны валют, валютын ханш нь хүсэлтийн JSON-д байхгүй боловч үр дүнд нөлөөлнө. Эдгээрийг setup-д тогтмол тодорхойлж, `OverBalance`, `OverLimit`, `Different` сонголтуудаар төлөөлүүлэв. Ханшийн хөрвүүлэлтийн дараах дүнгээр үлдэгдэл болон лимитийг шалгана.

### A2. Хязгаарлалт, үндэслэл ба тооцоо

**Алдааны давуу эрэмбэ (тестийн таамаглал):** `ERROR_NO_FROM → ERROR_FROZEN → ERROR_NO_TO → ERROR_SAME_ACCOUNT → ERROR_BAD_AMOUNT → ERROR_INSUFFICIENT → ERROR_LIMIT`. Учир нь эхлээд дансуудын хүчинтэй байдлыг, дараа нь мөнгөн дүн болон санхүүгийн хязгааруудыг шалгах нь тестийн хүлээгдэх үр дүнг тогтвортой тодорхойлоход тохиромжтой. Энэ эрэмбийг өгөгдсөн API тодорхойлолт заагаагүй тул хэрэгжүүлэлттэй тулгаж баталгаажуулаагүй.

- `[ERROR]`: дангаар нь шалгахад тодорхой алдаа өгөх хүчингүй сонголт; өөр алдаатай давхардах үед дээрх давуу эрэмбийг хэрэглэнэ.
- `[IF]`: утга зөвхөн тодорхой орчинд утгатай. Жишээлбэл `SameAsFrom`-ийг `From=Valid` үед, `OverBalance` болон `OverLimit`-ийг хүчинтэй илгээгчийн үлдэгдэл, лимит тогтоосон үед шалгана.
- `[SINGLE]`: валютын хөрвүүлэлтийн заагийг шалгах **тусгай нэг тест** (`S01`-ээс тусад нь `S12`); зөвхөн нэг удаа тусгайлан оруулна. `[SINGLE]` нь энд PICT-ийн бүх мөрөөс автоматаар хасах дүрэм биш, гараар сонгосон онцгой тест юм.

**Бүрэн олонлог:** `From(3) × To(3) × Amount(5) × Currency(2) = 90` боломжит ангиллын хослол.

**Гараар сонгосон хязгаарлалт:** `From ≠ Valid` үед `To=SameAsFrom`, `Amount=OverBalance/OverLimit`, `Currency=Different`-ийг хасна. `From=Valid` үед бүх сонголтыг үлдээнэ. Иймд:

- `From=Valid`: `1 × 3 × 5 × 2 = 30`
- `From=Frozen` эсвэл `Missing`: `2 × 2 × 3 × 1 = 12`
- **`90 → 42`** (тодорхойлсон нийцлийн хязгаарлалтуудын дараа).

Энэ нь бүх боломжит бодит банкны нөхцөлийн тоо биш, зөвхөн дээр тодорхойлсон категориудын загварын тоо юм. `[ERROR]`-ийг нэг мөрд хамгийн ихдээ нэгээр зөвшөөрөх тусгай дүрэм нэмбэл тоо өөрчлөгдөнө; PICT-ийн `~` хувилбарт үүнийг тусад нь харьцуулна.

### A3. Тестийн спецификацийн хүснэгт

Доорх `Amount` утгууд нь илгээгчийн валют руу хөрвүүлсний дараах шалгалтыг төлөөлнө. Давхар алдаатай мөрүүдэд A2-ын давуу эрэмбийг ашигласан. `S12`-ын USD дүн нь зөвхөн загварын ханшаар тооцсон жишээ.

| ID | From | To | Amount | Currency | Хүлээгдэх статус ба үр дүн |
|---|---|---|---|---|---|
| S01 | Valid | Valid | Normal | Same | `201 {"result":"OK"}` |
| S02 | Missing | Valid | Normal | Same | `200 {"result":"ERROR_NO_FROM"}` |
| S03 | Frozen | Valid | Normal | Same | `200 {"result":"ERROR_FROZEN"}` |
| S04 | Valid | Missing | Normal | Same | `200 {"result":"ERROR_NO_TO"}` |
| S05 | Valid | SameAsFrom | Normal | Same | `200 {"result":"ERROR_SAME_ACCOUNT"}` |
| S06 | Valid | Valid | Zero | Same | `200 {"result":"ERROR_BAD_AMOUNT"}` |
| S07 | Valid | Valid | Negative | Same | `200 {"result":"ERROR_BAD_AMOUNT"}` |
| S08 | Valid | Valid | OverBalance | Same | `200 {"result":"ERROR_INSUFFICIENT"}` |
| S09 | Valid | Valid | OverLimit | Same | `200 {"result":"ERROR_LIMIT"}` |
| S10 | Frozen | Missing | Zero | Same | `200 {"result":"ERROR_FROZEN"}` — давхар алдаа, эхний шалгалт |
| S11 | Valid | Missing | OverBalance | Same | `200 {"result":"ERROR_NO_TO"}` — давхар алдаа, хүлээн авагчийг түрүүлж шалгана |
| S12 | Valid | Valid | Normal (`100 USD = 350,000 MNT`) | Different | `201 {"result":"OK"}` — `[SINGLE]`, ханшийн хөрвүүлэлт |

**Тайлбар:** `S01` нь happy path; `S02–S09` нь тодорхойлолтод өгсөн бүх алдааны ангийг хамарна; `S10–S11` нь олон алдааны давуу эрэмбийг; `S12` нь хөрвүүлэлтийн тусгай нөхцөлийг шалгана. `S12`-ын 350,000 MNT нь 1,000,000 MNT үлдэгдэл, 500,000 MNT үлдсэн лимитийн аль алинд багтана.
